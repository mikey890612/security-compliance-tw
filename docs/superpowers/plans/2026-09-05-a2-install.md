# A2 Local Agent Skills Install Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a one-shot `./install.sh` that syncs a portable plugin snapshot, writes a root pointer, copies `sec-audit` / `sec-harden` / `sec-deliverables` into global Claude / Cursor / agents-hub skill dirs, and documents Cline / Windsurf / Copilot as doc-only.

**Architecture:** Manifest-driven bash installer (`install/targets.tsv`) with no yq/jq. Fix A: sync `security-compliance-tw/` to `~/.security-compliance-tw/plugin/`, write `~/.security-compliance-tw/root`, update three SKILL.md files to resolve `{ROOT}/references/…` via env then root file then `../..` fallback, then `cp -R` skills into agent dirs. Tests use a fake `HOME`.

**Tech Stack:** bash, TSV manifest, Python 3 stdlib only for `validate_kb.py` post-check, Markdown docs.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-09-05-a2-install-design.md`
- Repo root hosts `install.sh`
- Copy skills (not symlink) into agent dirs
- Plugin snapshot: `~/.security-compliance-tw/plugin/`
- Root pointer: `~/.security-compliance-tw/root` (one absolute path line)
- Env override: `SECURITY_COMPLIANCE_TW_ROOT` wins over root file
- Skills: `sec-audit`, `sec-harden`, `sec-deliverables`
- skill-dir: `claude` → `~/.claude/skills/{skill}`; `cursor` → `~/.cursor/skills/{skill}`; `agents-hub` → `~/.agents/skills/{skill}`
- doc-only: `cline`, `windsurf`, `copilot`
- Flags: `--dry-run`, `--no-backup`, `--only a,b`, `--list`
- Default backup then overwrite; `--only` does not skip plugin sync
- No yq/jq; macOS/Linux bash; missing python3 warns only
- No scanners; no sec-harden into business repos; no A3/Windows-first
- Do not change check KB / A1 status model
